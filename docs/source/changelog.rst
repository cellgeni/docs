Changelog
=========

A summary of the major changes to this documentation, newest first.

October 2026
------------

* Jira replaced by FreshService for all requests. Our own JupyterHub and Cloud GPU Notebooks were retired in favour of the Central JupyterHub, and the Notebooks page was folded into the Jupyter page.
* New site theme, a pipeline for reprocessing public data, an updated sceasy section and refreshed links.

January to May 2026
-------------------

* Conda module references changed from ``cellgen`` to ``ISG/conda``, with clearer instructions for cloning environments.
* Added details on the ``adata.X`` format and redacted contact information.

February to July 2025
---------------------

* Programme renamed from Cellular Genetics to Cellular Genomics.
* Documented Teleport login from GCP notebooks and fixed documentation build warnings.

November and December 2024
--------------------------

* New Conda and Farmer pages.
* Updated the Imaging and rclone pages.

October 2023 to September 2024
------------------------------

* Added a containers section to the JupyterHub page and refreshed the pipelines list.
* Fixed the Read the Docs build and added the README and licence.

January to August 2023
----------------------

* Martin Prete added as team leader and a link to Central IT's internal JupyterHub added.
* Updated the list of supported pipelines and the default JupyterHub RAM limit (20 GB).

September to December 2022
--------------------------

* New IGViewer page and About us section.
* Added cell2location to the pipelines and requests pages.

March to August 2022
--------------------

* Replaced Mattermost with Slack and added Visium to cellxgene instructions.
* Added ArrayExpress upload instructions and updated rclone for GPU cloud notebooks.

February 2022
-------------

* New Requests page describing how to raise tickets and what to include for each pipeline.
* Updated the GPU Cloud Notebooks and Imaging pages.

April to December 2021
----------------------

* New pages for raw fastq files, rclone and Cloud GPU Notebooks.
* Notebooks page expanded with a workflow flowchart and links to the repository.

January to March 2021
---------------------

* Added the Imaging section and data sharing and imaging pipelines.
* Expanded the JupyterHub page with resource descriptions and NFS mounting.

June 2019 to December 2020
--------------------------

* New Single Cell Visualizations chapter with sceasy conversion instructions.
* Jupyter user instructions imported from the notebooks repository and ML Warehouse queries updated.

May to December 2018
--------------------

* First version of the travel guide, with Globus data sharing, CRAM files and data submission.
* ML Warehouse pages added and the documentation moved to Read the Docs.
